The selected character is laid out to identify its font and glyph ID. Only then does the example
call `font.getOutline()`. That lazy numeric outline is passed directly to `generateSdf()`.

The returned `Uint8Array` is painted into ordinary `ImageData`. The SDF package knows nothing about
fonts, text layout, Three.js, canvas, or WebGPU; this application supplies the bridges.
