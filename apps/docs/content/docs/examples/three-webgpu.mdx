This example focuses on one job: painting ordinary text with an outer outline and one visual drop
shadow. Toggle either layer, change its color, and adjust the outline width or shadow shape without
reshaping the text or generating another glyph.

Width, offsets, and softness use the same units as the text layout. Shadow softness is a
distance-field falloff rather than a browser-style Gaussian blur. See the
[Three package guide](/docs/packages/three) for resource sizing, clipping, lighting, and scene
shadows, or the [color-glyph example](/docs/examples/color-glyphs) for COLR behavior.
