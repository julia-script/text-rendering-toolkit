title: Text Rendering Toolkit
description: A renderer-neutral text pipeline with an optional Three.js WebGPU frontend.
---

Text Rendering Toolkit is four small packages that turn font bytes and Unicode text into positioned glyphs,
CPU-generated signed-distance fields, and—only when requested—a Three.js WebGPU mesh.

## Start with the boundary you need

- Use `@text-rendering-toolkit/font` to parse fonts, shape text, and request outlines.
- Add `@text-rendering-toolkit/layout` to prepare raw multilingual text and position glyphs.
- Add `@text-rendering-toolkit/sdf` when a renderer needs a CPU-generated distance-field bitmap.
- Add `@text-rendering-toolkit/three-webgpu` only for the supplied Three.js WebGPU renderer.
